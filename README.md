# Loja de Brinquedos

Projeto desenvolvido em PHP para realizar o gerenciamento dos produtos de uma loja de brinquedos.

O sistema permite cadastrar, visualizar, modificar e remover produtos utilizando PHP, MySQL e PDO.

## Tecnologias

- PHP
- MySQL
- PDO
- HTML
